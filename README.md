Hello! Welcome to my Text Adventure game!
This is a C++ Text Adventure game based within the theme of "Lost Histories" and was made in Visual Studio Code 2022.
It starts with YOU! The main character sitting in front of their computer, staring at their screen until a unsual message pops up
and next you ascend into another dimension... Are you in a game? A simulation? Or perhaps in 13th century Bohemia? 
The game consists of interesting dialogue between you and a stranger who knows everything about you and multiple choices are to be made. 

The game may need improvements that I will be working on in the summer where I will have to change where the userHealth and userSkill and I will add a player class and place them there instead of in the runScenario parameters. 
I would also want to add a timer, some sound effects to certain parts of the game and perhaps change the index to alphabetical letters instead of numbers for better gameplay.
